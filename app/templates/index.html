Local Workflow

短视频爆款分析素材包生成器

当前主功能是单作品解析和创作者克隆实验室：从单条作品沉淀素材包，也可以导入一组对标素材，通过大模型蒸馏创作者规律。

Settings

API 与解析设置

API Key 只从本地 .env 读取，页面不提供保存入口。没有 API Key 也能完成下载和素材包生成。

单作品解析会自动选择该偏好下的候选资源，真实下载 URL 只保存在服务端。

AI 自动拆解

读取中
未配置时素材包仍会正常生成。需要自动拆解时，在 .env 中配置：
LLM_PROVIDER=openai_compatible
LLM_API_BASE=https://api.openai.com/v1
LLM_API_KEY=你的key
LLM_MODEL=支持图片输入的模型

Creator Clone Lab

            
创作者克隆实验室

            
导入一组对标素材，自由选择 N 条样本，通过大模型蒸馏创作者定位、选题规律、表达模板和可复用公式。

            
不登录、不使用 Cookie、不绕验证码、不绕风控；请确保你拥有素材分析权限。

            

                1. 导入素材
                2. 选择样本
                3. 富化证据
                4. 大模型蒸馏
                5. 导出规则

                            已有 Case 导入
                            
把已有素材包作为更高理解度样本参与账号级蒸馏。

                        

                        

                            
                        

                    

                    
                    
本轮先支持粘贴 case_id；批量选择已有 Case 的可视化入口后续接入。

                


                

                    

                        

                            高级 / 安全交接包
                            
适用于“本机助手采集，公开站继续分析”的链路。默认折叠为高级入口。

                        

                        

                            
                        

                    

                        
                        
                        
适用于“本机插件/助手扫描主页，公开网站继续分析”的链路。交接包必须声明不含 Cookie、登录 token 和签名媒体 URL。

                    

                        本地文件导入（后续接入）
                        
本轮不做复杂本地视频批量上传。需要本地视频时，请先走“单作品解析 / 本地素材包”能力，生成 Case 后再在“已有 Case 导入”中粘贴 case_id。
