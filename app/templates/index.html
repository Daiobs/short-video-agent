Local Workflow

短视频爆款分析素材包生成器

当前主功能是单作品解析：输入单条抖音作品链接或 aweme_id，生成本地素材包；配置大模型后可进行 AI 自动拆解。

Settings

API 与解析设置

API Key 只从本地 .env 读取，页面不提供保存入口。没有 API Key 也能完成下载和素材包生成。

单作品解析会自动选择该偏好下的候选资源，真实下载 URL 只保存在服务端。

AI 自动拆解

读取中
未配置时素材包仍会正常生成。需要自动拆解时，在 .env 中配置：
LLM_PROVIDER=openai_compatible
LLM_API_BASE=https://api.openai.com/v1
LLM_API_KEY=你的key
LLM_MODEL=支持图片输入的模型

Profile Scan

            
主页扫描

            
扫描公开主页作品列表，或粘贴多条作品链接作为稳定兜底。主页扫描只整理作品列表，下载、素材包和 AI 拆解仍复用单作品解析流程。

            
P2.0 不使用 Cookie、不登录、不绕风控；如果平台限制访问，请改用多作品链接粘贴或单作品解析。不会自动批量下载全部作品，也不会自动批量 AI 拆解。请确保你拥有相关内容的分析权限。
