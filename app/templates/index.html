Local Workflow

短视频爆款分析素材包生成器

当前主功能是单作品解析和创作者克隆实验室：从单条作品沉淀素材包，也可以导入一组对标素材，通过大模型蒸馏创作者规律。

Settings

API 与解析设置

API Key 和 Cookie 可保存到本机运行时配置，不进数据库、不上传云端、不提交 Git。没有 API Key 也能完成下载和素材包生成。

单作品解析会自动选择该偏好下的候选资源，真实下载 URL 只保存在服务端。

LLM_API_BASE=https://api.openai.com/v1
LLM_API_KEY=你的key

Creator Clone Lab

            
创作者克隆实验室

            
导入一组对标素材，自由选择 N 条样本，通过大模型蒸馏创作者定位、选题规律、表达模板和可复用公式。

            
默认不依赖 Cookie，不绕验证码、不绕风控；Cookie / Web API 仅作为可选增强层。请确保你拥有素材分析权限。

                2. 构建素材池
                3. 选择 N 条样本
                4. 证据富化
                5. 大模型蒸馏
                6. 可视化输出
