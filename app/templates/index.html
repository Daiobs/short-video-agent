当前主功能是单作品解析和创作者克隆实验室：从单条作品沉淀素材包，也可以导入一组对标素材，通过大模型蒸馏创作者规律。

API 与解析设置

单作品解析会自动选择该偏好下的候选资源，真实下载 URL 只保存在服务端。

Creator Clone Lab

            
公开主页扫描与创作者蒸馏

            
输入主页 URL 或 sec_user_id，先生成账号素材清单；公开读取受限时，使用本机插件 / 浏览器助手采集主页当前可见作品。扫描结果会按点赞、评论、发布时间等维度分层，用户手动确认样本后进入富化和大模型蒸馏。

            
当前默认不登录、不使用 Cookie、不绕验证码、不绕风控；公开主页能读取多少取决于平台公开返回内容。失败时优先走本机浏览器辅助采集，也可以用多作品链接、JSON / CSV 或已有 Case 兜底。请确保你拥有相关内容的分析、下载或使用权限。
