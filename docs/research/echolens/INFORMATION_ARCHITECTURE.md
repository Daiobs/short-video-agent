# 信息架构

## 已访问页面树

```text
EchoLens
├── /                         单作品检测、媒体结果、ASR/模型结果、转录历史侧栏
├── /douyin/favorites         收藏作品搜索与筛选
├── /douyin/following         关注账号搜索
├── /settings                 抖音账号凭证
└── /legal                    法律声明
```

共访问 5 个页面。路径来自页面可见链接或 Next.js 已加载的同源路由资源，没有枚举未公开接口。[E-003][E-010]

## 页面盘点

| 页面 | 目的与主要对象 | 可执行操作 | 输入 | 输出 | 状态与限制 |
| --- | --- | --- | --- | --- | --- |
| `/` | 处理单条抖音作品；对象为作品、媒体、转录和文本结果 | 新建转录、搜索历史、智能检测、清空、预览、下载、复制、切换 ITN/思考/模型、获取结果 | 分享链接；合法使用确认 | 类型、作者、标准链接、封面、视频、音频、标题、ASR/文本结果 | 空历史；处理中；ASR 提供方失败；成功 AI 结果未观察；可能产生调用的按钮未点击 |
| `/douyin/favorites` | 管理本人收藏作品 | 收藏/关注切换、搜索、按关注状态和发布时间筛选、分页/虚拟滚动、刷新、前往设置 | 作者或标题搜索；筛选条件 | 作品列表、数量统计 | 当前 0 条；未配置抖音凭证；刷新未执行 |
| `/douyin/following` | 管理本人关注账号 | 收藏/关注切换、搜索、刷新、前往设置 | 昵称或抖音号 | 关注账号列表 | 当前空；未配置抖音凭证；刷新未执行 |

| `/legal` | 说明定位、合法使用、隐私、禁止行为和责任 | 返回首页 | 无 | 法律声明 | 公开只读；没有发现明确禁止本次只读研究的条款 |

## 首页详细结构

### 左侧栏

- 收起侧栏。
- “新建转录”主入口。
- “搜索历史”输入。
- “收藏与关注”入口。
- 最近记录分组；当前显示“暂无转录历史”。

### 主工作区

1. 标题和定位说明。
2. 用户菜单：设置、退出登录。
3. 非商业学习与版权确认；链接到法律声明。
4. 分享链接输入和“智能检测”。
5. 检测结果：作品类型、作者、标准作品链接。
6. 媒体结果：封面、视频、音频的预览/试听与下载。
7. 标题结果和复制操作。
8. 转录/模型结果：处理文案、ASR 错误、ITN、思考模式、模型、获取结果。

这种布局把“数据获取”放在“AI 结果”之前，是产品定位的重要证据。[E-003][E-008]

## 收藏与关注工作区

收藏页采用左侧筛选、右侧结果的双栏结构：

- 顶部页签：收藏 / 关注。
- 搜索：作者或标题。
- 筛选：关注状态、发布时间。
- 统计：作品个数。
- 显示方式：分页渲染 / 虚拟滚动。
- 右上角刷新用于同步。

关注页沿用同一外壳，但输入改为昵称或抖音号，未观察到收藏页的统计和排序控件。[E-006][E-007]

## 状态覆盖

| 状态 | 是否观察到 | 表现 |
| --- | --- | --- |
| 空状态 | 是 | 暂无转录历史、暂无收藏视频、暂无关注用户 |
| 加载/处理中 | 是 | “转录任务处理中，完成后会自动展示结果” |
| 部分成功 | 是 | 媒体和标题已存在，但 ASR 失败 |
| 成功结果 | 部分 | 链接检测和媒体提取成功；AI/转录成功结果未见 |
| 失败状态 | 是 | `DashScope ASR` 的提供方错误文本 |
| 权限/凭证限制 | 是 | 收藏/关注提示先配置访问凭证 |
| 付费限制 | 未见 | `UNKNOWN` |

## 信息架构评价

优点是主路径短、页面数量少、结果紧贴输入。缺点是首页同时承担输入、检测结果、媒体下载、ASR、模型生成、历史和账号入口；任务成功、失败、继续、重试之间没有独立、可追溯的任务对象。对 `short-video-agent` 而言，应该借鉴它的聚焦呈现，而不应把现有 Case、Job、Evidence 和 Library 真源压回单页内存。
