# EchoLens 登录态黑盒研究

## 一页结论

EchoLens 是一个登录后使用的抖音单作品处理工具：用户粘贴分享链接，产品先识别作品与作者，提供封面、视频、音频和标题等可预览、下载或复制的结果，再尝试语音转写，并通过名为 `E1` 的模型入口生成进一步结果。它另有“收藏与关注”工作区，可在用户保存抖音访问凭证后同步本人收藏与关注内容。[E-003][E-004][E-006][E-007]

最终判断：**值得选择性参考，不适合作为整体架构或安全模型照搬对象。** 它最有参考价值的是单任务界面的聚焦程度、媒体结果的就地操作和明确空状态；它没有在本次只读样本中证明证据链、任务恢复、模型可追溯性或可执行的爆款拆解能力。[E-003][E-008]

## 最重要的三个发现

1. **核心不是“爆款分析”，而是“链接解析 + 媒体拆分 + ASR/文本结果”。** 首页把检测出的作品类型、作者、标准作品链接、封面、视频、音频和标题放在 AI 结果之前；这部分是已观察到的稳定价值。[E-003][E-008]
2. **产品体验窄而聚焦，但结果链条不够可追溯。** 页面有合法使用确认、处理提示、ASR 提供方错误、逆文本规范化、思考开关和模型选择，但未观察到逐条证据引用、事实/推断/建议分层、模型版本、数据来源或局部重算。[E-003][E-008]
3. **账号内容管理依赖远端保存完整抖音 Cookie。** 设置页要求粘贴“完整 Cookie”并执行“验证并保存”；法律声明称其经 HTTPS 传输并加密存储，但本轮无法验证实现。这与本地优先、最小权限和不托管平台凭证的北极星存在根本差异。[E-004][E-005]

## 最值得借鉴的三个能力

1. `ADOPT-NOW / P0`：将单作品链路明确拆成“输入 → 检测结果 → 媒体/证据 → AI 结果”，每一步保留已有部分结果。
2. `ADOPT-NOW / P0`：在封面、视频、音频、标题和作品链接旁提供就地预览、复制或安全下载动作。
3. `ADOPT-NOW / P0`：统一空状态和失败状态，直接告诉用户缺少什么、哪些结果仍可用、下一步去哪里处理。

## 最不应该照搬的三个能力

1. `DO-NOT-ADOPT`：让公开或远端服务保存用户完整抖音 Cookie。
2. `DO-NOT-ADOPT`：自动读取当前剪贴板内容并填入第三方链接，即使产品声称不读历史，也会增加意外暴露风险。
3. `DO-NOT-ADOPT`：输出没有来源定位、证据引用、模型版本和生成时间的 AI 文本，然后把它包装成可直接行动的分析。

## 与现有方向的关系

- EchoLens 更接近 `short-video-agent`，因为两者都从抖音作品输入出发，解析媒体和文本，再进入 AI 处理；按本报告的 17 项功能口径，保守重合度约为 **46%（±8%）**。
- 它与 `xingkong-workbench-secure` 的重合主要是人工触发、历史入口、状态提示和设置边界；远端 SaaS、完整 Cookie 托管和不可验证的服务端处理与本地优先方向相反，保守重合度约为 **24%（±8%）**。
- 直接参考对象应是 `short-video-agent` 的单作品入口、Case 结果页和错误呈现。
- 可作为共同基础设施参考的是任务状态、空状态、历史搜索、媒体动作和凭证能力提示；但凭证本身应留在本机连接器或显式 handoff 边界内。

## 研究完整度

- 产品研究完整度：**65%**。
- 架构推断整体可信度：**45%**；前端框架判断约 85%，后端、队列、持久化和托管判断低于 30%。
- 浏览页面：5 个（首页、设置、法律声明、收藏、关注）。
- 完成只读核心流程：5 条（登录态进入、已有检测结果查看、失败状态查看、凭证前置查看、收藏/关注空状态查看）。
- EchoLens 外部写入：0；付费操作：0；账户设置变更：0；敏感数据提交：0。

## 研究限制与未解决问题

- 未退出登录，因此未执行注册、登录和首次引导。
- 未点击“智能检测”“获取结果”“刷新”“验证并保存”，未创建新任务，也未触发可能收费的 AI/ASR 调用。
- 账户没有可见转录历史，现有样本的 ASR 失败，因此没有成功 AI 结果可供评价。
- 未观察到付费页、额度、订阅、导出报告、分享、反馈、批量任务、标签或版本记录。
- Chrome 的受限网络事件通道连续超时；只记录了页面资源清单中的脱敏路径，方法、状态码、响应结构、轮询频率和 Header 均保持 `UNKNOWN`。[E-010][E-011]
- 当前仓库未找到 `AGENTS.md`、`CODEX_MASTER_INSTRUCTION.md`、`PROJECT_NORTH_STAR.md`、`ROADMAP.md`、`SECURITY_BOUNDARIES.md`、`CURRENT_STATUS.md`；未伪造替代文件。[E-001]
- 本机未找到独立的 `xingkong-workbench-secure` 仓库；相关对比以用户给出的北极星和本仓库已存在的安全工作台合同为基线。[E-002][E-012]
