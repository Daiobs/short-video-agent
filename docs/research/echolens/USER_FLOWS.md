# 用户流程

## 执行边界

本轮只读观察已有页面和已有结果。以下流程使用三种状态：

- `OBSERVED`：实际进入并看到页面状态。
- `PARTIAL`：只观察到入口或已有中间状态，没有触发提交。
- `NOT-EXECUTED`：会创建记录、提交凭证、同步外部数据或可能产生费用，按治理要求停在确认前。

## 流程 1：登录态进入与首次首页

状态：`OBSERVED`（登录后）；注册和登录提交为 `NOT-EXECUTED`。

```text
入口：用户已打开并登录的首页
→ 用户输入：无
→ 系统校验：通过 /api/auth/me 类身份资源恢复账户态
→ 后台处理状态：首页直接显示账号菜单和现有输入状态
→ 输出结果：转录工作区、历史侧栏、收藏与关注入口
→ 后续操作：新建转录、设置、法律声明
→ 异常处理：本轮未观察到会话失效、MFA 或验证码
```

评价：登录后的入口直接、学习成本低。注册字段、邮箱验证、忘记密码和首次 onboarding 均未观察。[E-003][E-010]

## 流程 2：创建单作品检测任务

状态：`PARTIAL`。页面已有用户此前输入和已检测结果；未再次点击“智能检测”。

```text
入口：首页“新建转录”或分享链接输入框
→ 用户输入：抖音分享文本或作品地址；勾选合法使用确认
→ 系统校验：链接检测；具体规则与错误结构 UNKNOWN
→ 后台处理状态：页面展示检测与转录处理状态
→ 输出结果：作品类型、作者、标准作品链接、封面、视频、音频、标题
→ 后续操作：预览/试听、下载、复制、进入转录/模型结果
→ 异常处理：未观察无效链接错误；未执行提交
```

这个流程的主要优势是检测结果立即转成可操作对象，而不是只返回一段说明。[E-003]

## 流程 3：等待转录与查看失败状态

状态：`OBSERVED`（已有失败样本）。

```text
入口：已完成媒体检测的首页结果区
→ 用户输入：可选逆文本规范化、思考模式和 E1 模型
→ 系统校验：UNKNOWN
→ 后台处理状态：“转录任务处理中，完成后会自动展示结果”
→ 输出结果：当前没有有效转录；出现 DashScope ASR 提供方错误
→ 后续操作：“获取结果”按钮仍可用
→ 异常处理：显示原始提供方语义错误；没有观察到专门的重试、局部重算或恢复说明
```

评价：能明确告诉用户 ASR 失败是优点；同时出现“失败”“处理中”“获取结果可点击”会造成状态冲突，用户无法判断是自动重试、等待、重新提交还是转入另一个模型阶段。[E-008]

## 流程 4：使用媒体与字段结果

状态：`OBSERVED` 入口，下载/复制未执行。

```text
入口：检测结果区
→ 用户输入：点击预览、试听、下载或复制
→ 系统校验：浏览器内对象可用性；具体权限 UNKNOWN
→ 后台处理状态：媒体已经转换为页面 blob URL
→ 输出结果：封面、视频、音频、标题、作者、作品链接
→ 后续操作：在其他研究或创作流程中使用
→ 异常处理：未观察下载失败、过期或重新获取状态
```

这是本次研究中最明确、最可行动的结果层。它没有证明版权授权，法律声明把后续使用责任留给用户。[E-003][E-005]

## 流程 5：搜索历史结果

状态：`PARTIAL`。入口存在，当前没有历史记录。

```text
入口：首页侧栏“搜索历史”
→ 用户输入：关键词
→ 系统校验：UNKNOWN
→ 后台处理状态：UNKNOWN
→ 输出结果：最近转录记录；当前为空
→ 后续操作：理论上打开旧转录；未有样本验证
→ 异常处理：只观察到空状态
```

无法确认历史是否支持分页、筛选、删除、标签、归档、版本或批量操作。

## 流程 6：配置抖音访问凭证

状态：`NOT-EXECUTED`。停在提交前。

```text
入口：用户菜单“设置”或收藏/关注页“前往设置”
→ 用户输入：完整抖音 Cookie
→ 系统校验：“验证并保存”
→ 后台处理状态：当前显示“尚未验证”
→ 输出结果：预期为凭证有效状态
→ 后续操作：同步收藏与关注
→ 异常处理：自动获取在 macOS 上提示当前需使用开发者工具方式
```

预计动作：向 EchoLens 提交完整抖音 Cookie，并由服务端验证、保存。

风险：敏感凭证外发、账号权限范围不透明、平台策略变化、服务端存储不可验证。

是否可能收费：页面未提示；`UNKNOWN`。

执行结果：**未输入、未显示、未验证、未保存。**[E-004]

## 流程 7：同步和浏览收藏

状态：`NOT-EXECUTED` 同步；空状态与筛选 UI 为 `OBSERVED`。

```text
入口：收藏与关注 → 收藏
→ 用户输入：先配置凭证；可输入作者/标题和筛选条件
→ 系统校验：凭证是否已设置
→ 后台处理状态：右上角“刷新”预计触发同步，未点击
→ 输出结果：收藏作品列表、作品个数、分页或虚拟滚动
→ 后续操作：搜索、按关注状态/发布时间筛选
→ 异常处理：未配置凭证时显示阻断提示；当前 0 条
```

页面空状态清楚说明“使用右上角刷新按钮同步最新收藏”。由于刷新会读取账号数据并可能创建站内同步记录，本轮未执行。[E-006]

## 流程 8：同步和浏览关注

状态：`NOT-EXECUTED` 同步；空状态和搜索 UI 为 `OBSERVED`。

```text
入口：收藏与关注 → 关注
→ 用户输入：先配置凭证；可输入昵称或抖音号
→ 系统校验：凭证是否已设置
→ 后台处理状态：右上角“刷新”预计触发同步，未点击
→ 输出结果：关注账号列表
→ 后续操作：搜索账号
→ 异常处理：未配置凭证时显示阻断提示；当前为空
```

[E-007]

状态：`UNKNOWN`。

没有发现额度、账单、套餐或付费入口。未点击可能触发模型调用的“获取结果”，不能推断免费或无限。

## 用户请求的 12 类流程覆盖表

| 流程 | 结果 |
| --- | --- |
| 注册与首次进入 | 登录后入口已观察；注册未执行 |
| 创建分析任务 | 已有输入与检测结果；新建未执行 |
| 输入链接或上传素材 | 链接输入存在；上传未见 |
| 等待分析 | 处理中状态已观察 |
| 查看分析结果 | 媒体结果已观察；成功 AI 结果未见 |
| 展开证据或详情 | 媒体预览入口存在；证据引用未见 |
| 重试/重新生成/补充 | “获取结果”存在；语义与副作用未验证 |
| 保存/标记/分类 | 历史可能自动保存；标记/分类未见 |
| 搜索历史 | 入口存在；空状态 |
| 导出/复制/分享 | 字段复制和媒体下载存在；报告导出/分享未见 |
| 提交反馈 | 未见 |
| 查看额度和付费限制 | 未见 |

## 核心流程顺畅度

从粘贴链接到媒体结果的界面结构顺畅，字段和动作都靠近结果；从 ASR 失败到下一步则不顺畅，因为失败、处理中和可点击按钮同时存在，没有任务状态、重试范围、成本或保留结果说明。

若把“完整 Cookie → 刷新同步”视为第二核心流程，它的页面指引清楚，但安全成本过高，不符合 `xingkong-workbench-secure` 的本地优先和最小权限要求。

## 安全计数

- EchoLens 外部写入：0。
- 新建任务：0。
- 同步操作：0。
- 凭证验证/保存：0。
- 付费或模型提交：0。
- 账户设置变更：0。
